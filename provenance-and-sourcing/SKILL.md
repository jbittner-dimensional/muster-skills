# Provenance and Sourcing

This is the rule every other skill is built on. Read it first.

## The principle
1. **Every value shows its source and its age** — the system it came from and its
   `as_of`. A number with no time behind it is a rumor, not accountability.
2. **When sources disagree, show them all** — origin by origin. Never blend
   conflicting values into one confident-looking answer.
3. **The graph never picks a winner.** A human ruling or a certified policy decides;
   the graph faithfully keeps every version, including the ones that lost.
4. **Stale is not wrong, but it must be labeled.** A day-old warehouse snapshot is
   still useful — as long as everyone can see it's a day old.

Hold to this and the rest — [edw-fetch](../edw-fetch),
[quine-ingest](../quine-ingest), [conflict-adjudication](../conflict-adjudication) —
follow naturally.
